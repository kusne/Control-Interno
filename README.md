# Control Interno — BMZCN Desktop

Repositorio público destinado **exclusivamente a la descarga de instaladores de Control Interno (BMZCN Desktop)** para Windows.

## Descargar e instalar

Cuando se publique la primera versión pública, estará disponible en **[Releases — Descargar instalador](https://github.com/kusne/Control-Interno/releases/latest)**.

1. Abrí el enlace de Releases.
2. En **Assets**, descargá el instalador de Windows `.exe` (no descargues `Source code`).
3. Ejecutá el instalador para completar la instalación.

**Estado:** pendiente de la primera publicación pública del instalador.

## Código y actualizaciones

El código fuente y el proyecto de compilación permanecen en el repositorio privado de BMZCN. Este repositorio público solo debe contener documentación y archivos instaladores que se hayan revisado para distribución.

Las versiones publicadas aquí permiten descargar el programa desde otras PC sin instalar Git, Node.js o VS Code.

> Aviso: las compilaciones no firmadas digitalmente pueden mostrar una advertencia de Windows SmartScreen. Verificá que el archivo provenga de este repositorio oficial.
